# Rotina — tarefas da equipe

Uma ferramenta simples para organizar tarefas do dia a dia de uma equipe. O projeto usa HTML, CSS e JavaScript puro, sem instalação de dependências.

## Funcionalidades

- Cadastrar tarefas com responsável, prazo e prioridade
- Marcar tarefas como concluídas
- Filtrar por pendentes ou concluídas
- Buscar tarefas pelo nome
- Apagar tarefas concluídas com confirmação
- Salvar tarefas neste navegador

## Como usar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Cadastre tarefas, defina prioridade e, se quiser, responsável e prazo.
4. Marque tarefas como concluídas ou filtre a lista.

As tarefas ficam salvas no armazenamento local do navegador (`localStorage`). Isso significa que os dados ficam neste navegador e neste dispositivo; ainda não há sincronização entre pessoas ou computadores.

## O que o projeto pratica

- Variáveis, arrays e objetos
- Condições e funções
- Eventos de formulário
- Criação de elementos HTML com JavaScript
- Salvamento e leitura de dados com `localStorage`
